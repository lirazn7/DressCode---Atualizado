O **DressCode** é uma rede social mobile voltada para o mundo da moda. O aplicativo permite que usuários compartilhem seus looks do dia (OOTD), marquem marcas, interajam com outros entusiastas e gerenciem sua presença digital fashion.

Este projeto evoluiu de um protótipo com persistência local para uma aplicação **Full-Stack na nuvem**, utilizando Supabase para banco de dados relacional e armazenamento de mídia.

## ✨ Funcionalidades

### 👤 Usuário
- **Autenticação:** Cadastro e Login integrados ao Supabase.
- **Feed Dinâmico:** Visualização de posts em tempo real com carregamento otimizado.
- **Interatividade:** Sistema de curtidas (likes) e comentários.
- **Social:** Sistema de Seguir/Deixar de seguir outros perfis.
- **Upload de Mídia:** Upload de fotos da galeria diretamente para o Cloud Storage.

### 🛡️ Administrativo
- **Painel de Moderação:** Acesso exclusivo para administradores.
- **Gestão de Comunidade:** Visualização e exclusão de usuários e conteúdos.

---

## 🛠️ Tecnologias

- **Frontend:** [React Native](https://reactnative.dev/) & [Expo](https://expo.dev/)
- **Backend:** [Supabase](https://supabase.com/) (PostgreSQL & Storage)
- **Navegação:** React Navigation (Stack)
- **Ícones:** Material Community Icons
- **Estilização:** Expo Linear Gradient
